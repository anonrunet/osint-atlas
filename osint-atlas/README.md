# OSINT Atlas 2.0

Локальная исследовательская среда для поиска и организации законно доступных открытых источников. Проект — статическое веб-приложение: backend, аккаунт и отправка поисковых запросов на сервер Atlas не требуются.

## Каталог источников

- **421 уникальный источник** в **15 заполненных категориях**.
- Список пересобран с отбором по качеству и доступности; удалены битые ссылки, пустые шаблоны, устаревшие сервисы, сайты знакомств и низкокачественные агрегаторы.
- Все 421 финальных URL получили успешный GET-ответ в проверке 17 октября 2026 года. Проверка подтверждает доступность страницы, но не гарантирует работу платных функций, регистрацию или неизменность сервиса. Сторонние сайты могут позже менять адреса и правила.
- Google Dorks Generator создаёт 27 запросов по теме и ещё 7 для введённого домена/URL. Google открывается только после выбора конкретной ссылки.

## Функции

- Поиск по полному каталогу, категории, фильтры, сортировка и пагинация по 36 карточек.
- Избранное, история, язык, тема и настройки сохраняются локально в браузере.
- Интерфейс на русском, английском, французском, испанском и немецком; несколько тем оформления.
- Граф сущностей и связей, локальные дела, заметки, источники, даты фиксации, уверенность и шаблоны.
- Undo/Redo для графа, экспорт SVG/PNG/HTML и печать/PDF.
- Генератор Google Dorks с кликабельными ссылками; запросы не отправляются автоматически.

## Запуск

Открой `index.html` в браузере. Если браузер ограничивает работу локальных файлов, в папке проекта выполни:

```bash
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Источники и приватность

Данные приложения, избранное, история, настройки и графы хранятся в LocalStorage текущего браузера. В каталоге есть ресурсы с регистрацией или платными тарифами — это отмечено тегами. Atlas не сканирует сайты и не загружает данные автоматически. Используй источники законно, соблюдай условия сервисов и уважай приватность.

## Файлы

- `index.html` — разметка и стили.
- `app.js` — интерфейс, переводы, граф, настройки и сохранение.
- `data.js` — 421 отобранная ссылка и список 15 категорий.
- `dorks.js` — безопасные шаблоны поисковых запросов Google.
- `assets/` — favicon и аватар автора.

Для списка всех проверенных URL и HTTP-результатов см. отдельный отчёт аудита, приложенный к релизу.
