# OSINT Atlas

Локальный каталог публичных исследовательских ресурсов, созданный **@ceolika**. При запуске показывается лаконичный экран приветствия с названием проекта и кнопкой «Открыть Atlas»; переход открывает основной интерфейс сразу, без задержки. Регистрация и аккаунт не нужны: проект работает локально и не использует backend. Каталог включает 588 записей и 30 категорий. Для плавной работы инструменты показываются страницами по 36 карточек; поиск и фильтры применяются ко всему каталогу.

## Состав проекта

- `index.html` — интерфейс, адаптивная разметка и стили.
- `data.js` — каталог `window.OSINT_TOOLS` и список категорий `window.OSINT_CATEGORIES`.
- `app.js` — фильтрация, поиск, навигация, настройки, граф связей и локальное сохранение.
- `dorks.js` — генератор запросов Google Dorks для общих, официальных, научных и публичных источников.
- `assets/favicon.svg` — иконка проекта.
- `assets/author-avatar.png` — предоставленная автором аватарка @ceolika.

## Запуск

1. Распакуйте ZIP-архив.
2. Откройте папку `osint-atlas`.
3. Запустите `index.html` двойным щелчком.

Для иконок Lucide и Tailwind CDN требуется интернет. Базовые стили и все функции приложения находятся локально. Если `file://` ограничен настройками браузера, необязательно запустите сервер из каталога проекта: `python3 -m http.server 8000`, затем перейдите на `http://localhost:8000`. В Windows можно использовать `py -m http.server 8000`.

## Настройки

В правой части верхней панели находится переход к настройкам. Доступно 5 языков интерфейса: русский, английский, французский, испанский и немецкий. Переключаются темы Midnight, Slate, OLED, Nord, Dracula, Solarized Dark, Light, Paper и High Contrast; есть 8 цветов акцента, компактная/комфортная плотность, обычный/крупный текст и настройка уменьшения движения. Изменения применяются сразу. Кнопка с символом темы быстро переключает тему. Выбор сохраняется в LocalStorage текущего браузера.

## Генератор Google Dorks

В отдельном пункте меню введите тему или ключевую фразу — Atlas сформирует 27 вариантов для общих, официальных, научных, корпоративных и открытых источников. Если введён домен или URL, добавятся ещё 7 запросов к его публичным страницам. Каждый запрос показан как отдельная кликабельная ссылка Google; переход происходит только по выбору пользователя. Ввод обрамляется точной фразой, а генератор ориентирован на общедоступные материалы и не создаёт шаблоны для поиска паролей, персональных данных или закрытых административных интерфейсов.

## Граф связей

Раздел «Граф связей» поддерживает несколько локальных дел, заметки по делу и шаблоны цифрового профиля, доменной инфраструктуры, организации и проверки материала. Шаблоны создают только стартовые узлы и помеченные как непроверенные связи-гипотезы. Все дела и графы остаются в LocalStorage. Интерфейс сочетает панель свойств справа, палитру типов узлов внизу, рабочий холст, контекстные меню и масштабирование. Сначала выберите тип в нижней палитре: поле имени подставит подходящую подсказку (например, имя человека, email или номер телефона). Введите значение и нажмите «Добавить узел»; после добавления поле очищается. Выберите узел для редактирования справа. Связь создаётся через кнопку «Связать» в панели узла, затем нажмите на целевой узел. У ребра есть направление (вперёд, двустороннее или без стрелок), подпись, источник, заметки и уровень уверенности. Правый клик по узлу/холсту открывает быстрые действия. Перетаскивайте узлы левой кнопкой, холст — средней кнопкой; колесо меняет масштаб. Поддерживаются автоматическая раскладка и «Вписать». Удаление связи доступно в её правой панели. Очистка подтверждается повторным нажатием. Граф хранится только в LocalStorage браузера; внешние сервисы не опрашиваются.

## Добавление записи

Добавьте объект в массив `window.OSINT_TOOLS` в `data.js` перед закрывающей `];`:

```js
{
  id: "osint-0589",
  name: "Название ресурса",
  category: "Web Intelligence",
  description: "Кратко о назначении ресурса.",
  url: "https://example.org/",
  tags: ["Web Based", "Free"],
  isDead: false,
  keywords: "дополнительные слова для поиска"
}
```

У каждой записи должен быть уникальный ID и реальный URL. `category` должна совпадать с одной из строк `window.OSINT_CATEGORIES`. Допустимые теги: `Free`, `Registration Required`, `Local Installation`, `Google Dork`, `Paid`, `API`, `Open Source`, `Web Based`. Не указывайте `Free` или `isDead` без оснований.

## История, экспорт и быстрые переходы

Для текущего дела граф поддерживает отмену/повтор (кнопки и Ctrl+Z/Ctrl+Y; до 40 шагов в текущей сессии). Экспорт доступны в SVG, PNG и HTML-отчёт с визуализацией, заметками дела, узлами, направленными связями, источниками, датами и уровнем уверенности. «Печать / PDF» открывает диалог печати браузера — выберите «Сохранить как PDF». Быстрые переходы в инспекторе узла открывают внешние поисковые/справочные сайты с его значением. Atlas не отправляет запросы автоматически; проверяйте результат и правила стороннего источника.

## Локальные данные и приватность

Тема, язык, настройки отображения, избранное и последние 20 инструментов, открытых по ссылке в Atlas, сохраняются в браузерном LocalStorage. История не регистрирует действия за пределами приложения. Сайт не использует backend и не отправляет поисковые запросы на сервер проекта. Очистка данных браузера удалит сохранённые параметры.

## CDN и автономное использование

CDN-подключения используются только для Tailwind и Lucide. Для работы без сети скачайте официальные локальные версии ресурсов, подключите их из `assets/` вместо CDN и проверьте запуск в отключённой сети. Не добавляйте непроверенные скрипты.

## Ограничения и ответственное использование

Сервисы могут изменить доступность, цены, условия или адреса; автоматическая проверка ссылок не производится. Каталог сформирован на основе публичного OSINT Framework и может содержать устаревшие сведения. Прежде чем использовать внешний ресурс, самостоятельно проверьте его актуальность, правила и соответствие закону. Каталог не выполняет сбор данных, автоматические запросы к внешним сайтам, обход авторизации или анализ файлов.
