# OSINT Atlas

**Локальная исследовательская среда для поиска и систематизации открытых источников.** Каталог, граф связей и генератор поисковых запросов — в одном статическом веб-приложении.

[Открыть OSINT Atlas](https://anonrunet.github.io/osint-atlas/) · [Исходный код](https://github.com/anonrunet/osint-atlas/tree/main/osint-atlas)

![GitHub Pages deployment](https://github.com/anonrunet/osint-atlas/actions/workflows/deploy-pages.yml/badge.svg)

## Возможности

- Каталог из **588 ресурсов в 30 категориях** с поиском, фильтрами и постраничным выводом.
- Избранное и недавно открытые инструменты сохраняются локально в браузере.
- Интерактивный граф сущностей и связей, несколько локальных дел, заметки, источники, даты и уверенность.
- Шаблоны для начала исследования, отмена/повтор изменений и экспорт схемы/отчёта.
- Генератор Google Dorks: **27 поисковых вариантов по теме** и ещё **7 вариантов для домена или URL**. Запрос открывается только после клика.
- Интерфейс на русском, английском, французском, испанском и немецком; несколько цветовых тем.

## Быстрый старт

**Онлайн:** откройте [anonrunet.github.io/osint-atlas](https://anonrunet.github.io/osint-atlas/).

**Локально:** скачайте ZIP через **Code → Download ZIP**, распакуйте его и откройте `osint-atlas/index.html` в браузере. Если браузер ограничивает запуск локальных файлов, запустите в папке `osint-atlas` команду `python3 -m http.server 8000` и откройте `http://localhost:8000`.

## Конфиденциальность

Приложение работает без backend. Настройки, избранное, история и графы хранятся в LocalStorage текущего браузера. Atlas не отправляет поисковые запросы на собственный сервер. Внешний Google-поиск запускается только после того, как пользователь нажмёт на конкретную ссылку; запрос передаётся Google.

## Ответственное использование

Проект предназначен для работы с законно доступной публичной информацией. Соблюдайте применимое законодательство, условия использования источников и приватность людей. Наличие информации в поисковой выдаче само по себе не означает, что её дальнейшее использование допустимо.
